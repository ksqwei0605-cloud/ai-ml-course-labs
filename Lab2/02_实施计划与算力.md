## 4　按接口完成 Q2 的八个函数

只在 submission.py 中实现，沿用同设备 Tensor 路径、传入的 rng 和 dtype。保留 CPU/CUDA 与 float32/float64 支持，输入只读。独立小例子可用库核验，正式函数自行用 PyTorch 计算。

| 实现顺序 | 完成条件 |
|---|---|
| init_centers_kmeanspp | 首个中心均匀抽，后续按到已选最近中心的距离平方抽。总权重为零时从未选行均匀抽。 |
| assign_clusters | 计算 N×K 平方距离，截断浮点误差导致的负值，并列取小编号，返回编号和最小平方距离。 |
| update_centers | 非空簇求均值，空簇沿用旧中心。 |
| gmm_estep | 对角高斯在对数空间算各簇分值，用 logsumexp 归一化，返回逐行和为 1 的责任度及平均观测对数似然。 |
| gmm_mstep | 用责任度作权重更新混合比例、均值、逐维方差。负舍入误差截零后每维加 reg_covar。有效样本数 ≤1e−12 按协议报错，由框架处理失败重启。 |
| silhouette_score | 算同簇其他点的平均欧氏距离 a，到其他各簇平均距离的最小值 b，平均 (b−a)/max(a,b)。单点簇、a=b=0 时贡献零。接收既定子集。 |
| calinski_harabasz_score | 全量原始特征。用实际非空簇数，按自由度比较簇间和簇内离散度。簇内离散度恰为零按协议返回 1。 |
| davies_bouldin_score | 全量原始特征。用平均欧氏距离和中心间距，逐簇找最易混淆邻簇再取平均。两种精度均严格遵循 docstring 的全体近零与逐对恰零规则。 |

在 code/q2_clustering 运行 `python -m pytest -q` 与 `python extras.py self-check --device cpu`，然后在目标 GPU 跑 `python extras.py self-check --device cuda`。用小例子定位失败，覆盖重复点、并列距离、非连续簇号和单点簇。自检数据仅用于调试。

## 5　正式全量比较

1. 复核 X 的原始行序、(56000,512)、float32 和哈希。所有行参与每一次拟合。预处理、初始化、拟合、评价与选择全程只用无标签信息。
2. 第一轮保留 config.json。K=[5,8,10,12,15,20,25,30]，拟合 seeds=[17,42]，每组合 n_init=3，两方法合计 32 个候选、96 次初始化。KMeans 最多 200 次，GMM 最多 100 次，tol 均为 1e−4，reg_covar=1e−4，原始特征，float32。默认公共轮廓子集 3,000 行，无放回，抽样种子 20261011，CH/DB 全量。所有内部评价均在原始特征空间。
3. 运行 `python main.py --device cuda --output outputs_baseline`，再执行 `python extras.py check-output --output outputs_baseline`。保存日志。检查 manifest、runs、groups、selection、export_manifest，以及各候选的收敛、失败、实际簇数和簇大小。只有完成核验的正式输出才作为候选提交来源。
4. 为 T1 准备按“方法×K”分组的表，列主指标均值和种子间标准差、CH、DB、分区稳定性、最小簇和异常。训练目标在同方法内解释。惯性以平方距离和计，GMM 用平均对数似然，两者量纲不同。
5. 正式选择按配置的 selection_metric（默认 silhouette）比较所有计划种子均成功、主指标有效、实际簇数合规的组。均值并列到 1e−6 优先小 K 再优先 KMeans。组内 KMeans 取惯性最小的运行，GMM 取平均似然最大的运行，数值并列取较小种子。记录框架实际导出的唯一结果。

## 6　追上限的可选实验（先得到完整基线）

| 顺序 | 新实验及控制变量 | 从结果中判断什么 |
|---|---|---|
| 1 | 固定 K、预处理、重启数、评价子集，把共同种子从 2 个扩到 5 个，例如 17、42、73、101、137 | 比较组均值、标准差、极端种子和同一批样本两次预测分区的 ARI，检查结论是否依赖单次初始化。 |
| 2 | 同一组种子和选择规则，补齐高分区域邻近的整数 K；若资源充足，完整覆盖 K=5…30 | 观察指标峰值、平台、极小簇及跨种子重复性。两种方法使用相同 K，保留全部候选与失败记录。 |
| 3 | 固定候选网格、种子和评价子集，仅切换逐列标准化后重新拟合 | 若 KMeans、GMM 的排序改变，联系特征尺度与各方法距离假设解释。归档两种拟合空间，评价空间统一为原始 X。 |
| 4 | 固定已拟合候选与原设备/精度，仅改变轮廓抽样种子或样本数，每次只变一项 | 用 extras.py evaluate 回放，检查小簇是否被子集覆盖、排名是否稳定。改变主指标时另存配置并输出新目录。 |
| 5 | 若 GMM 多次失败或波动大，保留原结果，针对同网格只改变 reg_covar 或 n_init 再拟合 | 查有效成分、方差及重启日志，解释稳定性收益与代价。优先把最有证据的一项写成 T2。 |
